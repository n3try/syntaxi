ACCESSIBILITY

Accessibility statement

Syntaxi wants this download site to work for people using keyboards, screen readers, magnification, high-contrast settings, and reduced motion.

Target: WCAG 2.2 Level AALast reviewed: August 31, 2026
Our current target

The website is built and reviewed against WCAG 2.2 Level AA. This is a practical accessibility target, not a claim of third-party certification or a guarantee that every person will encounter no barrier.

Accessibility measures

  • Semantic headings, landmarks, lists, tables, and navigation labels.
  • A skip link that moves keyboard focus to the main content.
  • Visible keyboard focus and controls that do not require a mouse.
  • Text and control contrast designed to meet Level AA thresholds.
  • Layouts that reflow at narrow widths and support browser zoom.
  • A text alternative for the product screenshot.
  • Live status announcements when a download or app launch is requested.
  • Reduced-motion and Windows forced-colors support.
  • Plain language around downloads, security warnings, and data handling.

How the site is checked

The current pages are reviewed with automated accessibility checks, HTML validation, keyboard-only navigation, zoom and narrow-screen reflow checks, and color-contrast calculations. Automated tools do not catch every accessibility problem, so user feedback still matters.

Scope and known limits

This statement covers the pages hosted at n3try.github.io/syntaxi. GitHub’s release pages, issue tracker, download dialogs, Microsoft WinGet, Homebrew, operating-system warnings, and other third-party interfaces are outside this website’s control.

The downloadable Syntaxi desktop app is a separate interface and is not certified by this website statement. Its accessibility should be tested independently with keyboard navigation, Windows Narrator or macOS VoiceOver, text scaling, and high-contrast display settings.

Report a barrier

If something on this website blocks you, open an accessibility issue on GitHub. Include the page, what you were trying to do, your browser, and any assistive technology you were using.

GitHub issues are public. Do not include private or sensitive information. If you need a private response, ask the maintainer to provide a private contact method.

Standard used

The technical target is the Web Content Accessibility Guidelines 2.2 at Level AA. The U.S. Department of Justice web accessibility guidance also identifies WCAG as a useful technical standard for making web content accessible.
