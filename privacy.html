POLICY

Privacy Policy

This policy explains what happens to information when you visit the Syntaxi website, download a release, or use the Windows or macOS app.

Effective: August 30, 2026Last updated: August 31, 2026
The short version

Accounts are optional. If you create one, Supabase stores your email, display name, a protected password hash, and course progress. Lesson code stays on your computer. Cloudflare Turnstile helps block automated abuse. The site has no project-run advertising or analytics.

1. Who operates Syntaxi

Syntaxi is an independently maintained software project published through the GitHub account n3try. In this policy, “Syntaxi,” “we,” and “us” refer to that project maintainer.

2. What this policy covers

This policy covers the website at n3try.github.io/syntaxi and the official Syntaxi desktop releases linked from it. A third-party website, runtime, or service has its own policy.

3. Information handling

What happens in each part of the service
WebsiteThe site does not contain a project-run account form, contact form, analytics script, advertising tracker, or payment system. We do not receive a visitor database from the site.
Hosting and downloadsGitHub Pages and GitHub Releases deliver the site and files. GitHub may process IP address, device and browser details, request time, pages visited, download requests, cookies, and security logs under its own policies.
Course progressThe app saves completed lessons, XP, streaks, preferences, and achievements locally. If you sign in, those fields are also synced to the Syntaxi Supabase project so you can continue on another computer.
Lesson codeFiles you write in lessons stay in Documents\Syntax Forge Workspace. The current public build does not upload those files.
UpdatesThe installed app contacts the public GitHub Releases feed to check for and download updates. The request does not include course progress, but GitHub receives ordinary network metadata such as an IP address.
Runtime installsIf you choose a guided runtime install, the app starts Microsoft WinGet on Windows or Homebrew on macOS. The package manager and selected software publisher may receive ordinary installation and network data under their own policies.
Cloud accountsSupabase Auth processes your email, display name, account identifiers, authentication records, and a salted password hash. Syntaxi does not receive or store a readable password. Google sign-in may be offered as an optional alternative in a later build.
Abuse preventionCloudflare Turnstile processes ordinary device, browser, network, and challenge information when you create an account, sign in, or request a password reset. The result is used only to determine whether the request appears automated.

4. Cookies and tracking

Syntaxi does not add advertising SDKs or project-run analytics to this website. GitHub may use cookies and similar technologies while providing GitHub Pages and Releases. See the GitHub Privacy Statement and GitHub Cookies notice.

Cloudflare Turnstile may store or access information needed for security and bot detection. See the Cloudflare Privacy Policy. Supabase processes account and database information under its Privacy Policy.

We do not sell personal information or share it for cross-context behavioral advertising.

5. Why information is used

Local and synced progress is used to show your progress, continue lessons, remember learning preferences, and operate the software. Account data is used to authenticate you, verify your email, recover your account, secure the service, and associate synced progress with your account. GitHub-hosted requests deliver the website, releases, and updates. WinGet or Homebrew requests install software only after you choose an install action.

6. Storage, retention, and deletion

Account details and synced progress remain in Supabase while your account exists. You can delete the cloud account from the Account page in the app. That removes the authentication account and its synced progress. Local files remain until you remove them. Uninstalling may leave user data behind, so delete the legacy Syntax Forge app data folder and Documents\Syntax Forge Workspace if you also want to remove local progress and lesson files. Those folders keep the former name so existing progress and course files continue to work.

GitHub controls retention of its hosting, security, and download logs. Requests involving that data must be directed to GitHub.

7. Security

The site and release downloads use HTTPS through GitHub. Supabase protects account passwords with salted password hashing, and database row-level security restricts signed-in users to their own progress record. Desktop sessions use operating-system secure storage, including Windows Data Protection or the macOS Keychain. Published releases include SHA-256 checksums so you can verify file integrity. No internet service or local application can promise perfect security.

The current Windows installer is not Authenticode-signed. The macOS app has an ad-hoc integrity signature, but it is not Developer ID signed or notarized by Apple. Windows or macOS may block the first launch. Download only from the official release links on this site.

8. Children’s privacy

Syntaxi is a general-audience learning tool, but cloud accounts are not intended for children under 13. We do not knowingly collect account information from a child under 13. A parent or guardian should supervise a child’s use of the app, installation of runtimes, execution of downloaded software, and use of external links. Contact the maintainer if you believe a child under 13 created an account so it can be deleted.

9. Privacy choices and requests

You can use the app without an account. You can delete a cloud account and synced progress from the Account page. You can delete local progress and workspace files from your computer at any time. You can stop update checks by closing the app, and you control whether to start a runtime installation.

For a privacy question, open an item in the project issue tracker. Issues are public, so do not post an email address, account identifier, or other sensitive information. Ask the maintainer for a private contact method if your request requires one.

10. Service providers and location

GitHub hosts the website and releases, Supabase provides authentication and cloud storage, and Cloudflare provides Turnstile abuse prevention. The current Supabase project is hosted in the United States. These providers may process information in other locations described in their policies. Optional Google sign-in, if enabled, is also governed by Google’s privacy policy.

11. Changes to this policy

Material changes will be posted on this page with a new “Last updated” date. Check this page when a release adds accounts, analytics, payments, or another network service.
