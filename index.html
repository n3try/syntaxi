GET STARTED

From download to first program.

    Choose your platform

    Windows uses a small web installer. macOS uses a disk image for either Apple silicon or Intel.

  2. 02

    Check your runtimes

    Syntaxi detects Python, Node.js, Go, C++, C#, Lua, Luau, and Bash, with guided install actions for missing tools.

  3. 03

    Write and run code

    Lessons save to a dedicated workspace. Your programs run locally and their actual output is checked.
